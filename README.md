# TravelTrucks

TravelTrucks - це вебзастосунок для оренди кемперів, створений на Next.js.
Користувач може переглядати каталог кемперів, фільтрувати результати, відкривати детальну сторінку та надсилати заявку на бронювання.

## Сторінки

- `/` - головна сторінка з hero-блоком
- `/catalog` - каталог кемперів із фільтрацією та пагінацією
- `/catalog/[camperId]` - детальна сторінка кемпера з галереєю, відгуками та формою бронювання
- `404` - кастомна сторінка, якщо сторінка не знайдена

## Основні можливості

- фільтрація кемперів за локацією, типом кузова, двигуном і трансмісією
- пагінація та підвантаження нових карток
- детальна сторінка конкретного кемпера
- галерея фотографій
- відгуки користувачів
- форма бронювання з валідацією
- повідомлення про помилки та стан завантаження
- SEO-метадані для сторінок

## Запуск проєкту

Встановити залежності:

```bash
npm install
```

Запустити проєкт у режимі розробки:

```bash
npm run dev
```

Зібрати production-версію:

```bash
npm run build
```

Запустити production-сервер:

```bash
npm run start
```

Перевірити код лінтером:

```bash
npm run lint
```
